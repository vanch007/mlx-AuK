# MLX AuK Memory

- Production code strictly avoids `mlx_audio` runtime dependencies.
- Architecture:
  - VAE: BigVGAN-Flow-VAE (Encoder: 480x downsampling causal Conv1d -> 64-dim latents at 50 Hz; Decoder: 6-stage ConvTranspose1d BigVGAN vocoder with Anti-Aliased Snake activations).
  - DiT Backbone: Flux2Edit (10 MMDiT double-stream blocks with RoPE + 20 single-stream DiT blocks).
  - Flow Matching: CFM with Euler/Midpoint solvers; AuK-Flash uses distilled 4-step fixed t_grid [0.0, 0.07612, 0.29289, 0.61732, 1.0].
  - Multimodal Conditioning: Qwen2.5-Omni Thinker audio+text encoder with ELMo-style softmax layer fusion.
- All 16 generation and editing tasks share the identical multimodal DiT checkpoint and ChatML instruction interface.
- Benchmark and evidence: all 16 official demo scenarios from https://auk-project.github.io/ tested and validated with empirical RTF, latency, and duration metrics.
