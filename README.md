# MLX AuK

Standalone Apple Silicon MLX port of Tencent Hunyuan AuK with 1:1 full feature parity, native MLX architecture, and official web benchmark evaluation.

## Features
- All 16 generation, editing, enhancement, and separation tasks supported
- AuK-Flash 4-step distilled DiT (ultra-low RTF)
- AuK Base 32-step CFM DiT
- Native BigVGAN-Flow-VAE and Qwen2.5-Omni Thinker feature extractor
