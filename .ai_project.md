# MLX AuK

- Purpose: Standalone Apple Silicon MLX port of Tencent Hunyuan AuK with 1:1 feature parity, native MLX model architectures (BigVGAN-Flow-VAE, Flux2Edit CFM DiT, Qwen2.5-Omni Thinker feature extractor), model weight conversion, and official web benchmark evaluation with RTF metrics.
- Package: `src/mlx_auk`; Python >=3.10; MLX >=0.31.0.
- Interfaces: Python `AukInfer` / `load_model`, CLI `mlx-auk`, and batch benchmark runners.
- Upstream reference: `Tencent-Hunyuan/AuK` (arXiv:2609.08936, Sept 2026).
- Supported Tasks (16 tasks, 100% parity):
  - Speech Generation: Zero-Shot TTS, Instruct TTS
  - Content Editing: Speech Content Editing (insert/replace/delete), Lyric/Vocal Editing
  - Acoustic Editing: Pitch Editing, Speed Editing, Volume/Energy Editing
  - Paralinguistic Editing: Emotion, Timbre, De-accent, Nonverbal Editing, Whisper Conversion
  - Enhancement & Separation: Speech Enhancement, Speech Separation, Music/Vocal Separation, Super-resolution/Target Speaker Extraction
- Model Variants:
  - AuK-Flash: 4-step distilled consistency/DMD student (CFG=0.0, ultra-low RTF)
  - AuK Base: 32-step CFM teacher (CFG=2.0, high-fidelity research standard)
- Runtime Constraint: Zero dependency on `mlx_audio` at runtime; pure MLX computation on Apple Silicon GPU.
